# Early and late EEG signatures of reported visual awareness

Reanalysis of the public OpenNeuro dataset **ds006171** (Melcón et al., 2024; near-threshold Gabor detection, 128-channel EEG, no-cue task).
Seen vs unseen trials are compared with ERPs (VAN, P3b), time–frequency analysis, multivariate decoding / temporal generalization, and contrast-matched control analyses. Final sample: N = 31 (4 of 35 excluded by a priori criteria).

## Folder layout
```
eeg-awareness-ds006171/
├── ds006171/                  raw BIDS data (downloaded, not tracked)
├── derivatives/               preprocessed epochs (generated, not tracked)
├── output/                    results tables (.csv) and figures from the final run
├── code/
│   ├── 01_preprocess.py               filtering, ICA, epoching, artifact rejection (one subject per call)
│   ├── run_preprocess_all.sh          runs 01 for all subjects
│   ├── 01b_make_compact.py            128-Hz copies of epochs + QC table
│   ├── 02_group_compute.py            exclusion criteria, per-subject ERP / TFR / decoding
│   ├── 03_group_stats_figures.py      cluster permutation tests, ROI tests, Figures 1–4
│   ├── 05_robustness_checks.py        temporal-generalization extent, 100-draw contrast matching,
│   │                                  regression with trial number, Bayes factor (unseen vs catch)
│   ├── 06_blocked_cv.py               time-blocked cross-validation sensitivity analysis
│   └── 07_audit_manuscript.py         checks that reported numbers match the result files in output/
│                                      (consistency check, not an independent recomputation; see AUDIT.md)
└── EEG_awareness_analysis.ipynb       final notebook (Chinese comments): runs 02, 03, 05, 06 in one
                                       session and ends with a cell that prints every number reported
                                       in the manuscript; it is the single source of all reported results
```

## How to reproduce
```bash
pip install -r requirements.txt
openneuro-py download --dataset ds006171 --include "sub-*/eeg/*task-nocue*" \
    --include dataset_description.json --include participants.tsv
for s in ds006171/sub-*; do python3 code/01_preprocess.py $(basename $s); done
python3 code/01b_make_compact.py
python3 code/02_group_compute.py        # ~10 min (decoding)
python3 code/03_group_stats_figures.py
python3 code/05_robustness_checks.py
python3 code/06_blocked_cv.py
pandoc -t plain --wrap=none manuscript.docx -o manuscript.txt && python3 code/07_audit_manuscript.py manuscript.txt
# or, after preprocessing, run EEG_awareness_analysis.ipynb top to bottom
```
`01_preprocess.py` saves intermediate files in `derivatives/tmp_sub-XX/` and can resume if interrupted; these folders can be deleted afterwards.

## Software
Python 3.13, MNE-Python 1.12–1.13, scikit-learn 1.9, SciPy 1.18, statsmodels 0.15, pingouin.

## Data citation
Melcón, M., Stern, E., Arana, L., & Capilla, A. (2025). *EEG data during three near-threshold visual detection tasks* (Version 1.0.0). OpenNeuro. https://doi.org/10.18112/openneuro.ds006171.v1.0.0

## Final analysis path
The results reported in the manuscript come from: `01_preprocess.py` → `01b_make_compact.py` → `02_group_compute.py` → `03_group_stats_figures.py` → `05_robustness_checks.py` → `06_blocked_cv.py` (equivalently, the notebook). The contrast-control results reported in the manuscript are those of `05_robustness_checks.py` (100 draws; regression with contrast and trial number).

## What is and is not included
- **Included:** all code, the final notebook with outputs, and `output/` (result tables, figures, `erp_*-ave.fif` with per-subject ERPs, `group_data.npz` with per-subject decoding and time–frequency arrays, and `AUDIT.md`). These allow every reported statistic to be recomputed and audited without rerunning preprocessing.
- **Not included:** raw data (download from OpenNeuro, ds006171, CC0) and preprocessed epochs (~5 GB; regenerated by `01_preprocess.py`).
- **Reproduction status (details in `REPRODUCIBILITY.md`):** the full pipeline was run once from raw data (preprocessing of all 35 participants, then all group analyses). It has not yet been rerun from scratch in an independent environment.
